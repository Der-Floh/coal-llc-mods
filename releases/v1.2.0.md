# Coal LLC Mods v1.2.0

Game compatibility update for **Coal LLC v1.4.1.1**.

All 6 mods have been verified compatible with the new game version — no hooks broke, no vanilla API changes affected mod behaviour.

## Changes

### der_floh-performance_mod (1.1.0 → 1.2.0)

#### Added

- Optimised `lvl_from_global_pos_TIGHTFUNNEL` hook: computes `abs(x - 14)` once per tile instead of up to 19 times (same optimisation pattern as the existing STANDARD/FUNNEL/SKY_MINE/SHALLOW hooks)
- New game level types `SPARSE` and `SKYMINESPARSE` don't need dedicated hooks — they delegate to `STANDARD` and `SKY_MINE` which are already hooked

#### Changed

- Updated compatible game version to 1.4.1.1
