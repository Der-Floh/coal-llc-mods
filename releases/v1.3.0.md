# v1.3.0 – Bug fixes, new mod, settings cleanup

## New mod: der_floh-no_holes_mod

Fills the air-pocket holes that vanilla world generation leaves in roughly 30 % of underground tiles. After each chunk is generated, any tile that remained `EMPTY` is replaced with the correct solid background tile for that depth level.

| Depth levels | Fill tile       |
| ------------ | --------------- |
| 0–2          | BASIC_CLAY      |
| 2–5          | BASIC_STONE     |
| 5–8          | BASIC_ICE       |
| 8–11         | BASIC_FIRE      |
| 12           | BASIC_DARK      |
| 13           | BASIC_GREEN     |
| 14           | BASIC_ORANGE    |
| 15           | BASIC_PURPLE    |
| 16           | BASIC_DARKGREEN |
| 17           | BASIC_YELLOW    |
| 18           | BASIC_DARKBROWN |
| 19           | BASIC_DARKBLUE  |

Compatible with `der_floh-performance_mod` — listed as `optional_dependency` so it always runs as the outermost `generate_chunk` wrapper.  
Config: `enabled` (default: on) · `debug_logging` (default: off)

## Critical bug fixes: hook registration failures

Three mods were silently not applying their effects due to a GDScript limitation: referencing a mod's own `class_name` (e.g. `DerFlohPickaxeAoeMod`) from a hooks file prevents GML from loading that file at all — `class_name` declarations in dynamically-loaded scripts are not registered in GDScript's global class registry. The fix in each case is `load("res://mods-unpacked/.../mod_main.gd")` instead of a bare class name reference.

### der_floh-pickaxeaoe_mod (→ 1.1.2) — broken since 1.1.0

The `mine_action` hook was never registering, so vanilla ran instead: electric pickaxe and AOE ability dealt reduced vanilla damage ratios rather than the intended full 1.0× to all tiles. Also fixed: spark effect now uses the current vanilla `sparks_manager.add_spark()` pool instead of spawning 30 individual `Spark.tscn` nodes per swing.

### der_floh-performance_mod (→ 1.3.2) — broken since 1.3.0

The class name reference in `tile_map_manager.hooks.gd` prevented **both** hooks in that file from loading — `load_chunks` (zone-rebuild skip optimisation) and `apply_tile_effects` (direct dict iteration) were both inactive.

### der_floh-tick_upgrade_mod (→ 1.2.4) — broken since 1.2.1

The most severe case. Class name references for `_debug`, `get_preserve_duration`, and `get_always_tick_distant` in **both** hook files prevented all four hooks from registering. Tick-speed scaling, Preserve Effect Duration, and Always Tick Distant Tiles were all silently doing nothing.

## Settings: debug logging moved to config file (all mods)

The **Debug Logging** toggle has been removed from the in-game settings tab across all mods. Enable it by editing the config JSON directly:

```
%AppData%\Godot\app_userdata\Coal LLC\mods-storage\<mod_id>\configs\user.json
```

Set `"debug_logging": true` to enable. Affected mods: `ore_value_mod` · `effect_spread_mod` · `game_limits_mod` · `pickaxeaoe_mod` · `performance_mod` · `passive_drop_mod` · `tick_upgrade_mod`
