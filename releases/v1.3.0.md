Two new mods, critical bug fixes for three mods that were silently not applying their effects since April, and debug logging moved out of the in-game settings tab across all mods.

## Changes

### der_floh-no_holes_mod (new — 1.0.2)

New mod — fills the air-pocket holes that vanilla world generation leaves in roughly 30 % of underground tiles. Post-processes `generate_chunk`: any tile that remained `EMPTY` after generation is replaced with the correct `BASIC_*` background tile for its depth level.

#### Added

- Fills `EMPTY` underground tiles after each chunk generates: BASIC_CLAY 0–2 · BASIC_STONE 2–5 · BASIC_ICE 5–8 · BASIC_FIRE 8–11 · BASIC_DARK 12 · BASIC_GREEN 13 · BASIC_ORANGE 14 · BASIC_PURPLE 15 · BASIC_DARKGREEN 16 · BASIC_YELLOW 17 · BASIC_DARKBROWN 18 · BASIC_DARKBLUE 19
- Config: `enabled` toggle (default: on), `debug_logging` (default: off)
- `optional_dependencies: ["der_floh-performance_mod"]` — hooks as outermost `generate_chunk` wrapper; works with or without performance_mod installed

---

### der_floh-tick_upgrade_mod (new — 1.2.4)

New mod — injects "Poison Tick Speed" and "Fire Tick Speed" passive upgrade options into the in-game passive chooser. Each level adds +10 % to the respective tick rate, shown only when a poison weapon or flamethrower is equipped. Also keeps poison and fire effects ticking on out-of-range (unloaded) chunks.

#### Added

- Passive upgrades: **Poison Tick Speed** and **Fire Tick Speed** — +10 % per level; offered only when the matching weapon type is equipped
- Setting: **Always Tick Distant Tiles** — keeps poison/fire ticking on out-of-range chunks (default: on)
- Setting: **Preserve Effect Duration** — scales the stored tick count by the speed multiplier so total effect duration stays constant at higher tick rates (default: on)
- Tick-speed bonuses shown in the Tab-menu passive bonuses panel alongside vanilla passive rows
- `optional_dependencies: ["der_floh-performance_mod"]`

#### Fixed

- All hooks in both hook files were silently not registering since 1.2.1: class name references for `DerFlohTickUpgradeMod` prevented GML from loading the files. Tick-speed scaling, Preserve Effect Duration, and Always Tick Distant Tiles were all inactive. Fixed by replacing all bare class name references with `load(MOD_MAIN_PATH)`.

### der_floh-pickaxeaoe_mod (1.0.1 → 1.1.2)

#### Fixed

- `mine_action` hook was silently not registering since 1.1.0 (April 2026): `player_2.hooks.gd` referenced `DerFlohPickaxeAoeMod._debug` by class name, which GDScript cannot resolve for dynamically-loaded scripts. Electric pickaxe and AOE ability were dealing vanilla reduced damage ratios (0.8× chain falloff, 0.3× AOE) instead of the intended 1.0× to all tiles. Fixed by replacing all class name references with `load(MOD_MAIN_PATH)`.
- Spark effect now uses `tilemap.sparks_manager.add_spark()` pool to match current vanilla, instead of spawning 30 individual un-recycled `Spark.tscn` instances per swing

#### Removed

- Settings tab (its only control was the Debug Logging toggle); toggle `debug_logging` via the config JSON instead

---

### der_floh-performance_mod (1.2.0 → 1.3.2)

#### Fixed

- `tile_map_manager.hooks.gd` referenced `DerFlohPerfMod._debug` by class name, silently preventing **both** hooks in that file from registering since 1.3.0 — `load_chunks` (zone-rebuild skip optimisation) and `apply_tile_effects` (direct dict iteration) were both inactive. Fixed by replacing all class name references with `load(MOD_MAIN_PATH)`.

#### Removed

- Settings tab (its only control was the Debug Logging toggle); toggle `debug_logging` via the config JSON instead
